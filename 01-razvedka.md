# Задание 1. Разведка: как грузится ваша машина
### Определите режим загрузки и опишите структуру диска
1. `ls /sys/firmware/efi` - режим загрузки: если каталог существует - UEFI, если нет - BIOS.
```
ls: невозможно получить доступ к '/sys/firmware/efi': Нет такого файла или каталога
```
В моём случае режим загрузки через BIOS. Это подтверждается тем, что каталог `/sys/firmware/efi` отсутствует. В системах UEFI этот каталог обычно присутствует, поэтому машина загружается в режиме BIOS.

2. `lsblk -f` - разделы и файловые системы.
```
NAME   FSTYPE FSVER LABEL UUID                                 FSAVAIL FSUSE% MOUNTPOINTS
sda                                                                           
├─sda1 ext4   1.0         d4bf822a-2222-459a-9b85-106c7f63e9d3   16,1G     8% /
├─sda2                                                                        
└─sda5 swap   1           1d7bfddf-a296-481e-8ffd-b46c3bff3d2c                [SWAP]
sr0  
```
Описание структуры диска:
- sda - весь жесткий диск
- sda1 - корневой раздел с файловой системой ext4, смонтирован в /, это основной системный раздел
- sda2 - расширенный раздел, внутри которого находится логический раздел sda5
- sda5 - раздел подкачки, используется для виртуальной памяти и служит для обмена данными между оперативной памятью и диском
- sr0 - оптический привод

3. `lsblk -f | grep -i efi` В режиме BIOS раздел EFI отсутствует, поэтому команда будет показывать пустой результат.

4. `uname -r` - какое ядро сейчас работает
```
6.12.86+deb13-amd64
```
То есть в данный момент работает ядро Linux версии 6.12.86, собранное под Debian 13 на архитектуре amd64.

Расшифровка ядра:
- 6 - номер версии linux ядра
- 12 - второстепенный номер версии
- 86 - номер патча
- +deb13 - сборка созданная для debian 13
- amd64 - архитектура процессора 64-битного


5. `ls /boot/vmlinuz-*` - какие версии ядра установлены и доступны в меню
```
/boot/vmlinuz-6.12.63+deb13-amd64  /boot/vmlinuz-6.12.86+deb13-amd64
```
В системе установлены две версии ядра: 6.12.63 и 6.12.86. Обе версии находятся в каталоге /boot и доступны для загрузчика GRUB. Это показывает, что ОС поддерживает несколько вариантов ядра и может загружать одну из них при старте компьютера.

## Итоговый отчёт
1. В каком режиме загружается ваша машина, по какому признаку определили:
> Режим загрузки: BIOS. Признак: каталог `/sys/firmware/efi` отсутствует.

2. Таблица разделов с указанием назначения каждого:

| Раздел | Файловая система | Назначение |
|---|---|---|
| `sda1` | `ext4` | Корневой раздел `/` |
| `sda2` | — | Расширенный раздел, внутри которого находится `sda5` |
| `sda5` | `swap` | Раздел подкачки для виртуальной памяти |
| `sr0` | — | Оптический привод |

3. Сколько версий ядра установлено:
> Количество установленных версий ядра: 2

4. Если система в режиме UEFI — где смонтирован раздел ESP:
> Раздел ESP отсутствует, т.к. система загружается в режиме BIOS, а не UEFI
